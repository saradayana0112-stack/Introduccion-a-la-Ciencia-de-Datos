# Tutorial de Git

## Descripción

Este repositorio contiene el desarrollo de una actividad académica sobre el sistema de control de versiones Git y la plataforma GitHub. Incluye documentos tutoriales basados en el libro *Pro Git* en español, elaborados en formato Word y exportados a PDF.

## Objetivos

- Comprender los conceptos fundamentales del control de versiones con Git.
- Aprender a crear, clonar y administrar repositorios.
- Practicar los comandos `git add`, `git commit` y `git push`.
- Registrar y documentar los cambios realizados durante el desarrollo de la actividad.
- Elaborar documentos tutoriales en Word y exportarlos a PDF.
- Aprender a publicar y organizar archivos en GitHub.

## Estructura del repositorio

- `capitulos/`: contiene los documentos tutoriales de los capítulos en formatos Word y PDF.
- `documentos-txt/`: contiene archivos de texto utilizados para practicar modificaciones y seguimiento de cambios.
- `README.md`: describe el proyecto, sus objetivos y el proceso de trabajo.

## Proceso de trabajo

1. Crear un repositorio en GitHub.
2. Instalar y configurar Git en el computador.
3. Clonar el repositorio remoto mediante `git clone`.
4. Crear y modificar los documentos de la actividad.
5. Exportar los documentos de Word a PDF.
6. Preparar los archivos con `git add`.
7. Registrar los cambios con `git commit`, utilizando mensajes descriptivos.
8. Enviar los cambios al repositorio remoto mediante `git push`.
9. Verificar que los archivos estén disponibles en GitHub.
10. Preparar el informe de proceso con capturas de pantalla, dificultades, soluciones y conclusiones.

## Comandos utilizados

| Comando | Función |
|---|---|
| `git --version` | Consultar la versión instalada de Git. |
| `git clone` | Clonar un repositorio remoto. |
| `git status` | Consultar el estado de los archivos. |
| `git add` | Preparar archivos para una confirmación. |
| `git commit` | Registrar cambios en el historial. |
| `git push` | Enviar las confirmaciones a GitHub. |
