**Tutorial de Git**



**Descripción**



Este repositorio contiene el desarrollo de una actividad académica sobre el sistema de control de versiones Git y la plataforma GitHub.



**Objetivos**



\- Comprender los conceptos básicos de Git.

\- Aprender a crear y clonar repositorios.

\- Practicar los comandos `git add`, `git commit` y `git push`.

\- Documentar los cambios realizados durante la actividad.

\- Elaborar documentos tutoriales en Word y exportarlos a PDF.



**Estructura del repositorio**



\- `capitulos/`: documentos tutoriales de cada capítulo en formato Word y PDF.

\- `documentos-txt/`: archivos de texto utilizados para practicar modificaciones y seguimiento de cambios.

\- `README.md`: descripción del proyecto y del proceso realizado.



**Proceso de trabajo**



1\. Crear un repositorio en GitHub.

2\. Clonar el repositorio en el computador mediante `git clone`.

3\. Crear y modificar los documentos de la actividad.

4\. Preparar los cambios con `git add`.

5\. Registrar los cambios mediante `git commit`, utilizando mensajes descriptivos.

6\. Enviar los cambios al repositorio remoto mediante `git push`.

7\. Documentar el proceso y las dificultades encontradas.
